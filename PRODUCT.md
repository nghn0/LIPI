# Lipi
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Delegated by the user: local Python inference backend and a responsive browser frontend. No paid API required for core transliteration.
## Users
CS3235 undergraduate project team and evaluators. Assumed everyday users: students writing Hindi messages with a Roman keyboard.
## Product Purpose
Build professor's project 4, Hinglish Smart Writing Assistant, end to end with real pretrained AI4Bharat inference, a usable frontend, 30–50 task-specific test cases, quantitative evaluation, error analysis and repository documentation.
## Operating Context
Local academic demonstration, with downloads required during setup. User delegated project selection and implementation. Public hosting is optional for this local-model application.
## Capabilities and Constraints
Convert Roman Hindi into Devanagari, preserve punctuation and English terms, offer alternatives, save drafts and export. Improve phrasing and optionally translate with genuine configured model backends; unavailable models must be disclosed. No fabricated model outputs, benchmark scores or license claims.
## Evidence on Hand
User supplied course rubric. Official IndicXlit checkpoint and model documentation; model availability is being verified.
## Product Principles
Make the writing task immediate. Show what actually ran. Preserve user control over ambiguous words. Measure on representative examples and expose failures.
